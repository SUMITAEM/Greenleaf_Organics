1. Project Overview & Purpose

Greenleaf Organics is a complete AEM 6.5 website for a fictional certified organic food retailer based in San Jose, California. The site showcases the company's product catalog across four categories (Fresh Produce, Pantry Staples, Beverages, Wellness), a company story, a blog with articles, and a contact page — all built using Adobe Experience Manager best practices.

Business Purpose

The website serves as the digital storefront and brand hub for Greenleaf Organics, enabling customers to browse products, read blog content about organic living, subscribe to newsletters, submit contact inquiries, and manage a shopping cart and wishlist. It demonstrates a realistic e-commerce-ready AEM implementation suitable for a mid-size organic food retailer.

Target Audience

Health-conscious consumers, families seeking organic alternatives, and sustainability-minded shoppers in the United States — primarily the San Jose / Bay Area region, with national reach through the website.

9. Frontend — JavaScript Features

Shopping Cart localStorage-based cart with Add to Cart buttons, cart icon badge, slide-out drawer with quantity controls, subtotal calculation, and Clear Cart action.
Wishlist Heart icon toggle on product cards, localStorage persistence, header wishlist badge, slide-out drawer with "Move to Cart" action per item.
Product Filtering & Sorting Client-side filter bar on category pages — filter by badge type (Organic/Local/Vegan), sort by price (low/high) or name (A-Z).
Blog Comments Comment form + live comment list on blog article pages. Posts to BlogCommentServlet, auto-loads existing comments on page load.
AJAX Form Handling Contact form and newsletter signup submit via AJAX to Sling servlets. Toast notifications for success/error feedback. Loading states on buttons.
Mobile Hamburger Menu 3-line icon on mobile, slide-out navigation panel from the left with overlay. All nav items displayed as a vertical list with sub-items.
Back to Top Button Green circular button bottom-right, appears after scrolling 300px, smooth-scrolls to top on click.
Page Loading Animation Green spinner overlay on page load, fades out when page is ready. Safety timeout prevents indefinite blocking.

Key CSS Techniques

AEM Grid Override: AEM's default responsive grid uses float-based layout. The site overrides it with CSS Grid (grid-template-columns: repeat(4, 1fr)) scoped to main.container.responsivegrid to avoid affecting header/footer XFs.

Footer Flattening: Uses display: contents on nested AEM wrapper elements to make all footer content columns participate in a single 2-column CSS grid.

Navigation Flattening: Desktop nav uses display: contents on level-0 items (scoped via @media min-width) to flatten the AEM navigation hierarchy into a single horizontal row.

13. Key Features & Differentiators

Editable Templates 7 custom AEM Editable Templates with locked structure (header/footer XFs) and editable content areas with component policies.
Experience Fragments Shared header and footer as XFs — consistent branding across all pages with a single point of maintenance.
Navigation with Dropdowns Core Navigation v2 with CSS-only hover dropdowns on desktop and a JS-driven hamburger menu on mobile.
Form Processing Pipeline Custom servlets receive form data, OSGi service validates and stores in JCR, frontend provides AJAX submission with toast feedback.
Client-Side E-Commerce UX Shopping cart + wishlist with localStorage persistence, quantity management, subtotal calculation, and inter-feature integration (Move to Cart).
Content-Driven Architecture All page content authored in JCR/XML — no hardcoded content in templates. Authors can modify text, images, and links without code changes.
Responsive 4-Column Grid CSS Grid override of AEM's float-based system for product/category cards with responsive breakpoints (4 → 2 → 1 columns).
Automated Reporting OSGi scheduler runs hourly, aggregating newsletter subscriber and contact submission counts from JCR and logging reports.

14. Build & Deployment

Prerequisites

Java 11, Maven 3.6+, Node.js 14+, AEM 6.5 running on localhost:4502

Build Commands

CommandPurpose
mvn clean install -PautoInstallSinglePackageFull build + deploy to AEM
cd ui.frontend && npm run devBuild frontend (SCSS + JS) in dev mode
cd ui.frontend && npm run prodBuild frontend for production
mvn install -rf :greenleaf-organics-site.ui.appsPartial build starting from ui.apps
mvn install -rf :greenleaf-organics-site.ui.contentDeploy content only

Deployment Profile

The autoInstallSinglePackage Maven profile deploys the all package to http://localhost:4502 using the CRX Package Manager. The content filter uses mode="replace" for page content and mode="merge" for DAM assets.
